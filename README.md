# DAIS/DHS EAL Data Consolidation

A secure student assessment management system for tracking WIDA, MAP, WrAP, and Lexile scores.

## Features

- 🔐 **Secure Login** - Email/password authentication with role-based access
- 👨‍🏫 **Teacher View** - View student assessment data (WIDA, MAP, WrAP)
- 🛠️ **Admin Dashboard** - Add, edit, import, and delete student records
- 👑 **Super Admin** - Manage user accounts and access permissions
- 📊 **Analytics** - Interactive charts and year-over-year comparisons
- 📝 **Access Logging** - Track who viewed or edited student data
- 🔑 **Password Change** - Users can change passwords at login

## Tech Stack

- **Frontend**: HTML, CSS, JavaScript
- **Database**: Supabase (PostgreSQL)
- **Authentication**: Supabase Auth
- **Charts**: Chart.js
- **Icons**: Font Awesome
